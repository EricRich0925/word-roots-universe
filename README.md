# 富贵君疯狂英语·词根宇宙

词根词缀互动学习网站：137 个核心词根、17,223 个单词、7 条学习路线（零基础 / 四级 / 六级 / 考研 / 雅思 / 出国生活 / 跨境电商），按间隔重复、主动回忆等学习科学方法组织。

在线地址：https://fuguienglish.netlify.app

## 内容

- `index.html`：完整网站，单文件，浏览器直接打开就能用（离线可用，学习进度存在浏览器本地）。
- `data/master-affixes.json`：46 个前缀 + 137 个词根 + 33 个后缀。
- `data/roots-content.json`：137 个词根的记忆钩子与 624 条原创例句、79 个前后缀用法提示。
- `data/wordlists/`：7 条路线词表（每条路线一个文件）+ `meta.json`（覆盖率与统计），共 17,223 词（含词频、音标、释义、拆解标注）。

## 学习方法

每次学 5 个词根，学完马上测验；间隔复习 10 分钟 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天；复习先遮答案主动回忆；拆不开的词标为整体记忆，不编词源。

## 部署

把 `index.html` 传到任意静态托管（Netlify、Vercel、GitHub Pages 等）即可访问。
